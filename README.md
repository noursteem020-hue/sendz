# Sendz

Sendz is an AI-first, agent-native newsletter platform designed for automated growth. Built on top of a highly optimized email infrastructure, it allows content creators and businesses to run professional newsletters seamlessly through a beautiful web dashboard, a powerful REST API, or directly via an MCP (Model Context Protocol) client.

## 🚀 Key Advantages
- **Pay per Send, Not per Subscriber:** Stop wasting money on dormant or unengaged email addresses.
- **AI Agent Native:** Built-in MCP server that allows AI agents (like Claude or ChatGPT) to write, review, schedule, and analyze your campaigns autonomously.
- **Advanced Deliverability Guardrails:** Integrated smart pacing, list auto-cleaning, spam trap protection, and native Google Postmaster loop integration to keep your emails out of the spam folder.
