# Sendz

Newsletters your AI agent can run: write, review and send issues from the dashboard, the
REST API, or an MCP client — with built-in deliverability protections.

Sendz is a fork of [MailCheap](https://github.com/marclou/mailcheap) by Marc Lou, improved
for our market. Licensed under AGPL-3.0 (see LICENSE); the source of this running version
is this repository.
